# AuroraOS architecture dependency exceptions.
#
# Every line MUST use:
#
#     allow <source-glob> -> <target-glob> ; reason: <why this edge is legal>
#
# Lines without a reason are rejected by scripts/check_arch_layers.py.  Keep
# entries narrow: one reviewed edge category per line, not blanket wildcards.
#
# Note: the following categories are already modelled as legal by the scanner
# and do not need entries here:
#   - kernel/subsystem -> arch/HAL downward calls (AGENTS.md §5)
#   - HAL/arch/boot/board/adapter -> kernel/subsystem calls (implementation side)
#   - driver -> kernel/core Device/CSpace/sync primitives
#   - experimental -> stable APIs and experimental -> experimental
#   - anything -> metrics/* (cross-cutting collector, AGENTS.md §30)
